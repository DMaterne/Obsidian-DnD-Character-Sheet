# Spellcasting

You cast artificer spells using Intelligence.

Artificer spellcasting is prepared spellcasting. Your spell slots are supplied by the Artificer class progression in `Artificer.md`.

You can use thieves' tools, artisan's tools you are proficient with, or an infused item as a spellcasting focus where the artificer rules allow it.

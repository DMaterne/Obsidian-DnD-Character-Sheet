# Infuse Item

You learn artificer infusions and can use them to create temporary magic items.

The number of infusions known and the number of simultaneously infused items are supplied by the Artificer level progression:

- `infusions_known`
- `infused_items`

A dedicated infusion-selection system can later use these values to track known and active infusions.
